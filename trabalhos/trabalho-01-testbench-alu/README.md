# Trabalho 01 - Testbench da ALU

Exercício avaliativo da disciplina de Sistemas Digitais.

O trabalho usa uma ALU de 8 bits em SystemVerilog e um testbench para testar as operações principais.

A simulação e os testes foram feitos no QuestaSim.

## Arquivos

- `alu.sv` - módulo da ALU
- `alu_tb.sv` - testbench com os casos de teste
