# Requisitos do Trabalho T1

Anotações da aula usadas como base do projeto:

- trabalho em dupla ou trio;
- cobertura de código acima de 97%;
- testbenches self-checking;
- código sintetizável no Vivado;
- repositório Git com documentação;
- teste do projeto em uma placa FPGA;
- Half Adder e Full Adder de 1 bit;
- somador de 8 bits;
- ULA programável;
- operações de soma, subtração, multiplicação, comparação, AND, OR, NOT e XOR.

## Pontos para confirmar

Antes de fechar a ULA, ainda precisamos confirmar com o enunciado completo:

- como será codificada cada operação;
- qual comparação deve ser feita;
- se a multiplicação deve retornar 8 ou 16 bits;
- qual placa FPGA será usada e quais pinos devem entrar no arquivo XDC.
