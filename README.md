## Objetivo do repositório

Organizar os materiais e projetos produzidos ao longo da disciplina, registrando a evolução dos estudos e apresentando os resultados como parte de um portfólio acadêmico.

## Estrutura

| Pasta | Conteúdo |
| --- | --- |
| [`aulas/`](aulas/) | Anotações e exemplos desenvolvidos em aula |
| [`exercicios/`](exercicios/) | Exercícios práticos e listas resolvidas |
| [`trabalhos/`](trabalhos/) | Trabalhos avaliativos da disciplina |
| [`laboratorios/`](laboratorios/) | Experimentos, montagens e atividades de laboratório |
| [`testbenches/`](testbenches/) | Testes, simulações e arquivos de verificação |
| [`docs/`](docs/) | Relatórios, diagramas, imagens e documentação complementar |

## Organização dos conteúdos

Cada atividade deve ficar em uma subpasta própria, com nome curto e descritivo. Exemplos:

```text
aulas/01-introducao/
exercicios/01-portas-logicas/
laboratorios/01-circuitos-combinacionais/
trabalhos/01-nome-do-trabalho/
testbenches/01-nome-do-circuito/
```

Quando uma atividade tiver código, seu diretório deve incluir um `README.md` explicando o objetivo, os arquivos, como executar ou simular e os resultados obtidos.

## Tecnologias

As ferramentas, linguagens de descrição de hardware e ambientes de simulação serão registrados aqui conforme forem utilizados durante o semestre.
